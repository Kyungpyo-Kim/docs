my agent 개인정보처리방침

이 방침은 Kyungpyo Kim이 운영하는 개인용 Google 연결 앱 my agent에 적용됩니다.

1. 접근하는 데이터

승인된 OAuth 권한과 작업에 따라 Google 계정 식별 정보, Gmail의 발신자·수신자·제목·본문·첨부 정보, Calendar의 일정·시간·장소·참석자, Drive 파일의 메타데이터와 문서·스프레드시트 내용을 조회합니다. 기존 승인에는 연락처·Tasks·Slides 등 추가 서비스 권한이 포함될 수 있습니다. 승인된 권한과 실제로 조회한 데이터는 같지 않으며, 요청한 작업에 필요한 범위에서 접근합니다.

2. 이용 목적

계정 소유자가 요청한 메일 검색과 검토, 일정 확인, 문서 조회, 요약·분석 및 개인 업무 지원에 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. Google API로 얻은 데이터를 범용 AI·머신러닝 모델을 개발·학습·개선하기 위한 자료로 사용하지 않습니다.

3. AI 제공자와 전달 경로

작업은 운영자가 관리하는 환경에서 실행됩니다. 요약·분석을 위해 필요한 Google 데이터가 설정된 외부 AI 모델 제공자에게 전달될 수 있고, 응답을 받는 메신저 등에도 관련 내용이 전송될 수 있습니다. 이는 사용자 요청을 처리하는 추론·응답 경로이며, 데이터가 항상 로컬 기기 안에만 머무른다는 뜻은 아닙니다.

구체적인 제공자와 데이터 보관 조건은 사용 시점의 비서 설정 및 각 제공자의 정책·계약에 따릅니다. 이 페이지는 모든 외부 제공자의 무보관 또는 학습 제외 설정이 독립적으로 검증되었다고 보장하지 않습니다. 민감한 데이터를 처리하기 전에 해당 설정을 확인해야 합니다. 요청 처리·보안·법적 의무에 필요한 경우를 제외하고 데이터를 제3자에게 제공하지 않습니다.

4. 저장과 보관

OAuth 토큰은 운영자가 관리하는 인증 저장소에 보관합니다. 조회 내용과 요약은 작업 과정에서 대화 기록, 로그, 임시 파일 또는 사용자가 요청한 개인 메모에 남을 수 있습니다. 이 공개 GitHub Pages 사이트에는 Google 사용자 데이터나 인증 토큰을 게시하지 않습니다.

대화 기록·로그·백업·외부 제공자별 보관 기간은 다를 수 있으며 일괄 자동 삭제 기간을 보장하지 않습니다. 연결 해제는 앞으로의 API 접근을 차단하지만 이미 생성된 기록을 자동 삭제하지는 않습니다.

5. 권한 철회와 삭제 요청

Google 계정의 서드 파티 연결 관리에서 my agent의 접근 권한을 철회할 수 있습니다. 운영 환경에 저장된 토큰과 관련 기록의 삭제는 아래 연락처로 요청할 수 있습니다. 운영자가 관리하는 저장소의 삭제 범위를 확인하고, 외부 제공자에 남은 기록은 해당 제공자의 삭제 절차에 따라 처리합니다.

6. 보안과 제한된 사용

인증정보를 공개 저장소나 공개 페이지에 올리지 않으며, 작업 환경의 접근 통제와 전송 구간 보안을 사용합니다. 어떤 시스템도 완전한 보안을 보장할 수는 없습니다.
