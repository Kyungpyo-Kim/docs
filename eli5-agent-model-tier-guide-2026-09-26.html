그래서 각 모델은 어디에 둘까?

기본 배경 모델

GPT-6 Luna

심부름을 빨리 하는 자전거 배달원입니다. 값이 매우 싸고 빠르지만, 복잡한 길에서는 잘못 가도 모를 수 있습니다.

맡길 일: 하트비트, 크론 점검, 메일 분류, 추출, 포맷 정리, 단발성 작업.

안전장치: JSON 재시도 래퍼를 두고, 여러 단계 체인·중요한 작업에는 쓰지 않습니다.

빠른 대화 계층

GPT-6 Sol

보통의 실무를 빠르게 하는 작업자입니다. 응답 속도가 중요하고, 사람이 보고 있는 대화에 잘 맞습니다.

맡길 일: 빠른 질의응답, 조회, 간단한 초안, 가벼운 도구 작업.

주의: 실패를 스스로 고치려 할 수 있으므로, 복잡한 체인을 무감독으로 맡기지 않습니다.

중요 작업의 에스컬레이션

Opus 5.5

까다로운 고장을 볼 때 부르는 전문 기술자입니다. 느리고 비싸도, 실패를 말하고 긴 지시를 붙잡는 편이 중요할 때 씁니다.

맡길 일: 여러 단계 도구 체인, 긴 세션, 설계·검토, 사람이 읽는 중요한 결과.

장점: 원문 기준으로 실패를 감추지 않고 승인 게이트를 지켰습니다.

개인 에이전트의 현실적인 구성

권장 흐름: Luna가 토큰의 80% 이상인 배경 업무를 처리하고 → Sol(또는 동급 모델)이 상호작용을 맡고 → Opus가 막힌 일·고위험 일만 받습니다.

원문 추정 월 비용은 배경 Luna $0.50–1.50, 대화 Sol/동급 $3–6, Opus 에스컬레이션 $1–3으로 합계 약 $4–10입니다. 중요한 것은 가장 좋은 모델 하나가 아니라, 알맞은 일을 알맞은 모델로 보내는 라우터입니다.
